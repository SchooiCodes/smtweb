FAQ

Schooi's Multitool FAQ - Windows Multitool & Toolkit

Answers to the most asked questions about SMT, the Windows multitool for Windows 10 & 11.

What is Schooi's Multitool (SMT)?

Schooi's Multitool (SMT) is a free, open-source Windows multitool and Windows toolkit for Windows 10 and Windows 11. One console bundles 137 Windows tools - IP & networking utilities, Windows & Office activator, bootable USB creator (Ventoy), Easy DNS changer, CLI task manager, security & privacy tools, 40+ app installers and more.

Is Schooi's Multitool free and safe?

Yes - SMT is 100% free and open-source (MIT). The Windows tool source is on GitHub for review. Run it only on PCs you own and use security research tools only with authorization.

How do I install SMT on Windows 10 or Windows 11?

Open PowerShell as Administrator and run: irm "https://smt.gleeze.com/" | iex . Mirrors smt.farted.net and getsmt.ftp.sh also work. Or download Schooi's Multitool Setup.exe from GitHub and run it.

Why is SMT the best Windows multitool / Windows toolkit?

Unlike one-off Windows tools, SMT gives you 137 Windows utilities in one Windows toolbox - no hunting for scattered scripts. Network tools like IP Geolocator, system tools like Bootable USB Creator and DNS Changer, plus app installers - all updated to v2.3 and searchable from the homepage terminal.

What Windows versions does SMT support?

Schooi's Multitool supports Windows 10 and Windows 11 (64-bit). A few tools also run on Windows 7. The Windows multitool auto-detects your OS and enables console colors on Windows 10+.
