About

What is SMT?

Schooi's Multitool - Your All‑in‑One Workflow Assistant

What began as a small collection of batch scripts has become a massive developer toolbox with over 100 tools. SMT streamlines everything from network diagnostics and system activation to automated app installations and security research.

Version 2.3 brings a Bootable USB Creator, Easy DNS Changer, School Utilities, Auto‑Update System, and much more - all accessible from a clean console interface.

Install

Install SMT

One command. No install wizard. Windows 10/11 (64-bit).

PowerShell — run as Administrator
irm "https://smt.gleeze.com/" | iex

Windows Defender or SmartScreen may flag the script because it downloads and runs an executable. SMT is open-source — review the source if unsure.

Mirror commands

  • irm "https://smt.farted.net/" | iex
  • irm "https://getsmt.ftp.sh/" | iex
  • irm "https://getsmt.us.to/" | iex
