Accessibility Statement

Last updated: 2026

Schooi's Multitool ("SMT") is committed to making this website usable by as many people as possible. We aim to conform to the WCAG 2.1 AA guidelines.

Measures we take

  • Semantic HTML with a logical heading hierarchy and landmarks (nav, main, footer).
  • A "Skip to content" link is provided at the start of every page for keyboard and screen-reader users.
  • Visible keyboard focus indicators on all interactive elements.
  • ARIA labels on icon-only controls (social links, theme toggle) and on the tools search field.
  • Responsive layout that works from mobile to desktop, with a collapsed navigation menu on small screens.
  • Respects the operating system "reduce motion" preference where supported.

Known limitations

Some tool names and badges use emoji for visual flavor; these are decorative and have adjacent text. Decorative entrance animations are used on scroll. If you experience difficulty, you can disable animations at the operating-system level.

Feedback

If you encounter an accessibility barrier on this site, please tell us so we can improve. Email schooibusinessinquiries@gmail.com and we will respond as soon as possible.

Compatibility

This statement applies to the SMT marketing website (this domain). The SMT application itself is a Windows console program and follows its own interface conventions.
